# دعوتي — دعوات زفاف إلكترونية

تطبيق Next.js (واجهة أمامية وخلفية في مشروع واحد) لإنشاء دعوات زفاف إلكترونية مخصصة. كل دعوة صفحة ويب لها رابط خاص، وتدعم العربية بالكامل (اتجاه من اليمين لليسار، خطوط عربية، تاريخ هجري، أرقام عربية).

## المميزات

الميزات مبنية على بحث في أشهر منصات الدعوات الرقمية (Greenvelope وMinted وWedsites ومنصات عربية مثل مسرّة ودعوة فرح ومناسبات):

| للضيف | للعروسين (لوحة التحكم) |
|---|---|
| ظرف متحرك بختم شمع يحمل الأحرف الأولى + موسيقى خلفية | محرر بمعاينة مباشرة داخل إطار جوال |
| رابط شخصي يعرض اسم الضيف وعدد المقاعد المخصصة له | إضافة ضيوف فرادى أو دفعة واحدة (لصق من Excel) |
| عدّاد تنازلي بتوقيت مكان الحفل | إرسال الدعوة عبر واتساب برسالة قابلة للتعديل |
| التاريخ الميلادي والهجري (أم القرى) | متابعة من فتح الدعوة ومن رد، وإحصائيات الحضور |
| خريطة مدمجة وزر للاتجاهات | تصدير قائمة الضيوف إلى CSV/Excel |
| إضافة الموعد إلى تقويم Google وApple وOutlook | استقبال يوم الحفل: مسح رمز QR بالكاميرا أو إدخاله يدوياً |
| تأكيد الحضور أو الاعتذار مع عدد المرافقين | إدارة التهاني (إخفاء أو حذف) |
| بطاقة دخول QR بعد تأكيد الحضور | ١٥ قالباً و١٦ خطاً، مع حفظ تصميمك كقالب خاص |
| دفتر تهاني | عدة حفلات في دعوة واحدة (رجال، نساء، ملكة، حناء) |
| صورة خلفية للقسم الأول مع طبقة شفافة وتمويه | تعديل كل ألوان القالب (٨ ألوان) كلٌّ على حدة |
| ألقاب للعروسين (المهندس، الدكتورة…) أو بدون | تغيير الزخارف والنقشة والزوايا والإطار وشكل الصورة |
| حركات ظهور وعناصر متساقطة قابلة للاختيار | ترتيب الأقسام وإخفاؤها وتغيير عناوينها |
| خلفية صورة أو فيديو للقسم الأول أو لكل الصفحة | ٥ تخطيطات للقسم الأول، ٤ أشكال للتاريخ، ٣ للعدّاد، ٤ للبطاقات |
| مونوغرام مخصص على ختم الظرف | «فاجئني بتصميم فريد» + توليد لوحة ألوان من لون واحد |
| برنامج الحفل، معرض صور، ملاحظات | إخفاء اسم العروس، أو إظهاره أولاً |
| صورة معاينة جميلة عند المشاركة في واتساب (OG) | دعوة بالعربية أو الإنجليزية، ونشرها أو إخفاؤها |

لا حاجة لإنشاء حساب: عند إنشاء الدعوة يحصل صاحبها على **رابط إدارة سري**. يُخزَّن المفتاح مشفراً (SHA-256) في قاعدة البيانات، ويُحفظ على جهازه في كوكي `httpOnly`.

## التقنيات

- **Next.js 16** (App Router + Route Handlers) و React 19 و TypeScript
- **Tailwind CSS v4** و `motion` للحركات
- **Drizzle ORM + libSQL**: ملف SQLite محلي أثناء التطوير، و[Turso](https://turso.tech) في الإنتاج
- **Zod** للتحقق من البيانات في الواجهة والخادم
- `next/og` لتوليد صورة المعاينة، مع أداة تشكيل للحروف العربية (`src/lib/arabic-shaping.ts`) لأن Satori لا يدعم تشكيل العربية

## التشغيل

```bash
npm install
cp .env.example .env.local   # اختياري
npm run dev                  # http://localhost:3000
```

تُطبَّق ترحيلات قاعدة البيانات (`drizzle/`) تلقائياً عند أول طلب. بعد تعديل `src/lib/db/schema.ts` شغّل `npm run db:generate`.

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير |
| `npm run build && npm start` | بناء وتشغيل الإنتاج |
| `npm run lint` / `npm run typecheck` | فحص الكود |
| `npm run db:generate` | توليد ترحيل جديد |
| `npm run db:studio` | متصفح قاعدة البيانات |

## النشر

- **Vercel**: عيّن `DATABASE_URL=libsql://…` و`DATABASE_AUTH_TOKEN` (من Turso) و`NEXT_PUBLIC_APP_URL`. نظام الملفات على Vercel مؤقت، فلا تستخدم ملف SQLite هناك.
- **خادم خاص / Docker**: يكفي `file:./data/app.db` مع وحدة تخزين دائمة لمجلد `data/`.

الصور تُضغط في المتصفح (JPEG بحد أقصى 1600px) وتُخزَّن في قاعدة البيانات، والصوت حتى 8MB، والفيديو (MP4/WebM) حتى 20MB. على Vercel حجم الطلب محدود بـ 4.5MB، فالأفضل هناك استخدام رابط خارجي للفيديو أو تخزين ملفات خارجي (S3/R2). يُتحقق من نوع كل ملف مرفوع عبر توقيعه (magic bytes).

## هيكل المشروع

```
src/
  app/
    page.tsx                  الصفحة الرئيسية
    create/                   إنشاء دعوة (محرر + معاينة)
    demo/[theme]/             معاينة حية للقوالب
    i/[slug]/                 صفحة الدعوة العامة + صورة OG + ملف تقويم .ics
    manage/[id]/              لوحة التحكم (+ access لتبديل رابط الإدارة بكوكي)
    api/                      invitations, guests, rsvp, wishes, media, checkin, export, view, slug
  components/
    invitation/               مكونات صفحة الدعوة
    editor/                   المحرر
    manage/                   الضيوف، التهاني، الاستقبال
  lib/
    invitation-schema.ts      مخطط محتوى الدعوة (Zod): مصدر الحقيقة لكل الخيارات
    themes.ts, fonts*.ts      القوالب والخطوط
    dates.ts                  المناطق الزمنية والتاريخ الهجري
    db/                       Drizzle schema والاتصال
```

التصميم يعتمد على `resolveStyle()` في `themes.ts`: كل خيار شكل أو لون قيمته الفارغة `""` تعني «من القالب»، فتغيير القالب يحافظ على بنية التخصيص.

محتوى الدعوة محفوظ كـ JSON مُتحقَّق منه في عمود واحد. لإضافة خيار جديد: أضفه إلى `invitation-schema.ts` مع قيمة افتراضية (الدعوات القديمة تأخذها تلقائياً)، ثم إلى المحرر وإلى `InvitationView`.
